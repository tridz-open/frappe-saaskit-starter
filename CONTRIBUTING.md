# Contributing

frappe-saaskit-starter is early alpha software and is not currently accepting pull requests or outside contributions. Pull requests will be closed without review.

**Issues are welcome.** If you find a bug or a problem, please [open a GitHub issue](https://github.com/tridz-open/frappe-saaskit-starter/issues/new/choose).

## What to include in a bug report

- The version or release tag you are using (release tag or commit, and the SDK version).
- Your environment: OS, runtime version, and how you installed it.
- What you did (exact commands or code), what you expected, and what happened instead.
- The full error output or stack trace.
- A minimal reproduction if you can make one.
- **Remove secrets and account data first**: tokens, session cookies, API keys, emails, hostnames, team ids.

## Security issues

Do not file security problems as public issues. See [SECURITY.md](SECURITY.md).
